# Дополнительный локальный детектор объектов

`yolo_candidates.py` использует официальные веса YOLOv8n COCO только для поиска объектов и выбора фрагментов: телефон, сумка, рюкзак, чашка, бутылка. Наличие объекта не является доказательством нарушения, принадлежности сотруднику или запрета конкретным правилом. Кассовые документы, деньги и движения рук этот детектор не классифицирует.

Веса: https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8n.pt

SHA-256 загруженного файла: `f59b3d833e2ff32e194b5bb8e08d211dc7c5bdf144b90d2c8412c47ccfc83b36`. GitHub не предоставил отдельный upstream digest для этого исторического asset; этот отпечаток фиксирует полученный по HTTPS файл, а не независимую подпись издателя.

Источники: https://docs.ultralytics.com/models/yolov8/ и https://github.com/ultralytics/ultralytics/blob/v8.3.221/LICENSE.

Установлены из PyPI в отдельную `.yolo-deps`: ultralytics 8.3.221, opencv-python-headless 4.12.0.88, torchvision 0.21.0, psutil 7.1.0. Используется уже установленный CPU PyTorch 2.6.0. Инференс только на CPU, максимум 2 потока; облачные интеграции, DNS-проверки, телеметрия и автоматическая установка отключены. Кадры и вырезанные области сохраняются только локально.

API: `LocalYoloCandidates(image_size=960).propose_video(path, duration, output_dir=local_folder, deadline=time.monotonic()+budget)`. Допускается `image_size=640`; размер фиксируется до итоговой проверки качества. Входной кадр сохраняется в исходном разрешении, без рамок и растяжения; внутренний letterbox YOLO сохраняет пропорции. Результат содержит `timecode`, `kind`, `score`, `bbox_xyxy`, `bbox_normalized`, `frame_width`, `frame_height`; `bbox_xyxy` — пиксели сохранённого кадра, `bbox_normalized` — доли ширины/высоты в диапазоне 0–1. При `output_dir` добавляются `frame_path`, `crop_path`, `crop_bbox_xyxy`. Срок проверяется между операциями; отдельный вызов PyTorch не прерывается жёстко.
