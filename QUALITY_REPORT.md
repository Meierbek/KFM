# KFM — проверка качества

**Улучшение точности не получено: refined + Qwen3-VL 4B дала 5 правильных ответов из 13, базовая схема + 2B — 7 из 13.** Базовая схема назвала нарушением каждое видео; все шесть отрицательных примеров получили ложную тревогу. Поэтому обе схемы остаются ненадёжными, а более высокий результат 2B не означает достаточного качества.

Refined 4B не активирована. В сайте сохранена экспериментальная Qwen3-VL 2B Instruct; это отсутствие подтверждённой замены, а не рекомендация доверять её выводам.

Qwen3-VL 8B Instruct загружена, но не активирована. Единственная контролируемая попытка загрузки для синтетической проверки остановлена через **12,422 секунды**: свободный резерв памяти Windows (commit) упал до **1,606 GiB**, ниже защитного порога 2 GiB. До старта свободны были 7,628 GiB физической памяти и 7,555 GiB commit; минимальный остаток физической памяти во время попытки — 3,046 GiB. Завершён только проверенный новый процесс этой попытки, очистка прошла без ошибок. Модель не вернула ответа, разбор видео набора через 8B не выполнялся, **её точность не проверена**. Это результат одной попытки при данном состоянии компьютера, а не вывод о невозможности запуска на любом оборудовании с 16 GiB памяти.

Числовой журнал попытки: `local_review/evaluation/large8b_resource_preflight.json`. После очистки список загруженных моделей Ollama пуст, процесс попытки отсутствует, запас памяти восстановился. Активная конфигурация сайта с 2B не изменена.

## Ограничения проверки

Из 42 исходных файлов получены 40 уникальных записей после объединения двух групп побайтовых дубликатов по SHA-256. Фиксированное разделение: 27 dev и 13 holdout. Ранее использованные dev остались в dev; у положительного дубликата объединены опорные таймкоды.

Holdout — внутренняя отложенная часть того же небольшого набора, а не новые записи из других отделений или камер. Исходные видео ранее проходили предварительный локальный разбор. Подбор настроек по результатам holdout превращает последующую оценку в исследовательскую; этот генератор проверяет сопоставимость файлов, но не может доказать отсутствие такой настройки.

В исходной разметке нет точных меток юридических категорий для независимого измерения правильности каждой ссылки. Проверяется бинарный ответ на уровне видео. По этим числам нельзя утверждать, что модель понимает любые нарушения, подтверждать отсутствие действий между выбранными кадрами или гарантировать качество на произвольном видео.

Успешные программные тесты проверяют API, форматы, расчёты и защиту данных. Они не являются измерением точности распознавания. Время измерено в условиях соответствующих локальных прогонов; одинаковые видео не гарантируют одинаковую нагрузку оборудования.
